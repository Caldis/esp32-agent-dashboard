# v2.0.0 — Public 2.0: SDK + Marketplace Launch

Released 2026-05-23.

## Summary

Twenty-one v0.x + v1.x versions shipped overnight. v2.0.0 is the
public-launch marker: the project is feature-complete to its v1
roadmap, the plugin SDK is stable, and the v2.x cycle opens with web
mirror + native desktop ports.

## What's new since v1.0.0

- v1.1.0 — plugin SDK with signed component packs + linker-section
  discovery (PLUG1)
- v1.2.0 — multi-device fleet discovery (mDNS + COM + cache)
- v1.3.0 — BLE-pushed WiFi provisioning
- v1.4.0 — voice (TTS prompt-read + 4-class STT decision)
- v1.5.0 — session replay with rotary-encoder scrubbing
- v1.6.0 — mobile companion design (Flutter, sibling repo)
- v1.7.0 — power management (4-stage sleep + USB-C PD readout)
- v1.8.0 — i18n (en / zh-CN / ja string registry)
- v1.9.0 — on-device AI summarisation (SmolLM-135M, llama2.c port)

## Marketplace

`tools/sdk/scaffold.py my-plugin` generates a new plugin project.
`tools/sdk/sign_plugin.py` signs it with the user's author key.
Future cycles add a hosted marketplace at
`dashboard-plugins.dev` (TBD) for browse + install.

## API stability

- Wire protocol `dash *` verbs are stable. New verbs land via the v2
  protocol negotiation (`dash hello protocol_version=v2`).
- `~/.claude-buddy/config.toml` schema is stable. Keys can be added.
- `esp_harness.client.*` is the stable host-side library API.
- The plugin SDK (`plugin_api.h`) is at ABI version 1; breaking
  changes increment.

## What's next (v2.x)

- v2.1.0 — web dashboard mirror (browser-side LVGL via WASM)
- v2.2.0 — native desktop client (Tauri)
- v2.3.0+ — community-driven; track on the GitHub project board
